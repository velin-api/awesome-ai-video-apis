# Contribution Guidelines

Thanks for helping keep this list accurate.

## Adding an entry

- The service must be callable by developers: a public API, an SDK, or open weights you can run yourself. A product with no API does not belong here.
- Link to the provider's official pricing or API docs page, not a blog post or a third-party review.
- Use this format and keep the section in alphabetical order:

  `- [Name](https://link) - One-sentence description. Price: concise published price.`

- State only prices and limits the provider publishes. If a number is not on the official page, leave it out.
- For open models, state the license shown on the official repo or model page instead of a price.
- One service per pull request, unless the PR updates a whole section.

## Updating an entry

Prices change all the time. If a price or limit changed, or a service shut down, open a pull request with the link to the official page that shows the change.
